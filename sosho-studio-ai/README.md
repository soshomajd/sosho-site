# SoSho Studio

وب‌سایت دوزبانه SoSho Studio با دستیار فروش هوشمند، ثبت سرنخ در D1 و زیرساخت پاسخ‌گویی خودکار به دایرکت اینستاگرام.

## توسعه محلی

```bash
npm install
npm run dev
```

برای بررسی کیفیت و ساخت خروجی استقرار:

```bash
npm run lint
npm run build
```

تنظیمات اتصال سرویس‌ها و مسیرهای API در [docs/AI_SALES_SETUP.md](docs/AI_SALES_SETUP.md) توضیح داده شده است.
