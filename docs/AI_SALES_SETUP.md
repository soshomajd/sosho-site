# راه‌اندازی دستیار فروش SoSho Studio

## قابلیت‌های فاز اول

- چت شناور فارسی و انگلیسی در تمام صفحات سایت
- جمع‌آوری مرحله‌ای نوع سایت، هدف، امکانات، سبک، محتوا، بودجه، زمان و اطلاعات تماس
- دسته‌بندی پروژه در سه سطح اقتصادی، حرفه‌ای و اختصاصی
- ذخیره سرنخ، مکالمه و پیام‌ها در D1
- خروجی ساختاریافته از OpenAI Responses API و ادامه امن با پرسش‌های ثابت هنگام قطع AI
- دریافت وب‌هوک اینستاگرام، جلوگیری از پردازش تکراری و ارسال پاسخ خودکار
- محدودیت ۳۰ پیام کاربر در ساعت برای هر مکالمه

## متغیرهای محیطی

مقادیر واقعی را فقط در Secret Manager میزبان قرار دهید و داخل کد یا Git ثبت نکنید.

| متغیر | کاربرد |
| --- | --- |
| `OPENAI_API_KEY` | فعال‌سازی پاسخ هوشمند |
| `OPENAI_MODEL` | مدل پاسخ‌گو، مقدار پیش‌فرض `gpt-5.6-luna` |
| `META_VERIFY_TOKEN` | توکن دلخواه و محرمانه برای تأیید وب‌هوک |
| `META_APP_SECRET` | بررسی امضای پیام‌های Meta |
| `META_INSTAGRAM_ACCESS_TOKEN` | ارسال پاسخ در دایرکت |
| `META_GRAPH_VERSION` | نسخه Graph API، مقدار پیش‌فرض `v26.0` |

نمونه نام متغیرها در فایل `.env.example` قرار دارد.

## مسیرهای API

| مسیر | روش | کاربرد |
| --- | --- | --- |
| `/api/health` | `GET` | بررسی وضعیت اتصال AI، دیتابیس و اینستاگرام |
| `/api/sales/chat` | `POST` | پردازش پیام چت وب‌سایت |
| `/api/meta/webhook` | `GET` | تأیید callback در Meta |
| `/api/meta/webhook` | `POST` | دریافت پیام دایرکت |

Callback URL اینستاگرام برابر است با:

```text
https://YOUR-DOMAIN/api/meta/webhook
```

## دیتابیس

مهاجرت اولیه در `db/migrations/0000_ai_sales.sql` است و این جدول‌ها را می‌سازد:

- `leads`
- `conversations`
- `messages`
- `webhook_events`

در OpenAI Sites اتصال D1 با binding به نام `DB` تعریف شده است. برای استقرار مستقل Cloudflare باید یک D1 database بسازید، migration را اجرا کنید و همان binding را به Worker اضافه کنید.

## نکته قیمت‌گذاری

AI فقط سطح مناسب را پیشنهاد می‌دهد و قیمت قطعی نمی‌سازد. قبل از فعال‌سازی پیشنهاد قیمت خودکار، مبلغ پایه و ضرایب SoSho برای هر نوع سایت باید در موتور قیمت‌گذاری مرحله بعد ثبت شوند.
